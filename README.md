## **一、先搞清楚：AS9929 到底比普通线路强在哪？**

很多新手看到"9929""CN2""CMIN2"这一堆术语就头大，简单梳理一下。

AS9929 是中国联通的精品国际线路，独立于普通 AS4837 网络运行，主要服务于政企客户。它的特点是：

- **晚高峰不塌方**：因为带宽资源独占，不像 163/4837 那样跟全网用户挤一条路，晚上八九点丢包率通常能控制在 3% 以内，非高峰期基本低于 1%
- **回程路由干净**：日本机房的 AS9929 VPS，回程国际段一般走香港 AS10099 转接，再回到国内联通 AS9929 骨干，对联通和电信用户都比较友好
- **延迟稳定**：从东京到国内联通节点，物理延迟本来就有优势，加上精品线路，RTT 通常能稳定在 50ms 上下

但 AS9929 不是万能的。它对联通用户最友好，电信用户需要 CN2 GIA 配合，移动用户则需要 CMIN2。所以现在真正能打的日本 VPS，基本都做"三网回程"——电信走 CN2、联通走 AS9929、移动走 CMIN2，三条精品线一起拉满。
